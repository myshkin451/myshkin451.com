# 0017: 个人平台中的学习室

Status: Accepted implementation; deployment and browser acceptance tracked separately

Date: 2026-10-15

## 依据

站主要求从个人平台进入并使用哲学学习室，公开界面不透露具体报考目标。学习室已有独立
课程、学习记录与登录服务，个人网站的公开内容服务和账号系统继续保留原职责。

## 决定

- 新增 `/study`，保留 Myshkin 451 的品牌入口，在页面内嵌现有学习室，并提供“独立打开”。
  网站导航使用中性“学习”，页面标题使用“哲学学习室”；不公开学校名称、考试目标或专业代码。
- `/study` 直接渲染轻量页面，不读取个人网站的内容数据库，也不增加个人网站登录门槛。
  学习内容和记录仍由学习室验证账号后提供；公开页面只有入口与登录界面。
- 网站仅允许嵌入 `https://philosophy-study.vercel.app`。学习服务只允许指定个人网站来源嵌入，
  不开放任意网站，也不为内嵌增加 API 跨域权限或传递登录令牌。
- 两套服务保持现有数据和账号归属，不同步密码、不增加单点登录。学习账号可在内嵌页面登录；
  密码找回可独立打开学习室完成。不同浏览器上下文可能需要分别登录，不承诺会话互通。
- 学习入口不加入站点地图，并使用不索引的元信息。认证负责保护学习内容，不以隐藏链接代替权限。
- 内容服务异常页也提供学习入口，使个人网站数据库不可用时仍能到达独立的学习页。

## 验证与边界

发布验收需实际确认内嵌加载、登录、刷新、移动尺寸、复制操作及公开信息边界；生产部署和
个人账号验证结果另记状态板，不以本补丁或构建通过代替。未迁移课程、学习原答或个人网站内容。
后续更换域名时同时更新入口和双方的精确来源约束。
