## 依据

站主希望实际持续使用个人网站：经常发布类似微博的短文、长文，并从这里进入个人学习。
本人明确选择 `myshkin451.com`，并希望学习功能可以公开、个人学习记录保持私有。
另一个学习任务正在更新哲学平台的动态路线、练习与日常学习接续，本仓库不重复实现。

## 决定

- 保留现有 Next.js、Supabase 与 Vercel 架构和已接受的视觉基础。首页优先展示最近随记，
  然后展示作品；站主获得直接写随记、写文章、回工作台及学习的入口。普通访客不显示创作操作。
- 保存草稿与公开发布继续分开。服务端提交成功即为写入成功，后续读取失败应明确提示刷新，
  不能误报写入失败并诱导重复提交。随记自动保存不再读取整站内容。
- 正式域名为 `myshkin451.com`；2026-10-23 已在本人 Vercel 团队核实注册，根域已连接原项目，
  `www` 以 308 跳转根域。具体 HTTPS、认证邮件与生产切换结果以状态板和上线记录为准。
- 个人网站负责公开随记、文章、作品与学习入口；哲学、雅思继续保持各自的业务和学习数据。
  不合并数据库，不传递登录令牌，不把学习原答、反馈、进度自动发布为个人站内容。
- 学习功能可公开、记录按账号私有是已确认的目标，**不是现有服务已经实现的多用户能力**。
  课程/练习是否可公开、按用户隔离及未登录行为由对应学习项目实现和验证；教材扫描不因入口
  公开而成为公开材料。本站仍遵守不公开具体报考目标的既有边界。
- 哲学先沿用现有 `/study` 和独立打开；新主域上线时必须协调学习服务的精确嵌入来源。
  雅思当前只有规划，没有可用应用，不设置虚假的可用入口；实际交付后再接入。

放宽权限政策/CSP；10 月 23 日按本人明确授权完成首位已验证账号的站主授予。日常学习动态更新
留给正在进行的哲学任务；主站不把学习规则或私有 Git 仓库内容当作可公开网站素材。
