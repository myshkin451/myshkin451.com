# 0014：单人发布的随记

Status: Accepted; implemented

Date: 2026-09-21

## 目的

站主希望在同一平台容纳长篇文章和即时想法，并明确确认：只有本人能够发布，已发布内容公开
可读，草稿仅本人可见。栏目使用直接的名称「随记」，不建立多作者社交网络。

## 决定

- 为现有 Entry 增加 `note` 类型。沿用 Supabase 管理者授权、草稿与公开副本、留言审核和备份。
  不部署第二套 Memos 服务，不拆分数据库或身份系统。
- `/notes` 提供按发布时间倒序的正文时间线、月份/主题/文字筛选，每次显示 20 条；
  `/entry/<UUID>` 继续作为稳定公开链接。修改和重新发布保留初次发布时间。
- `/studio/notes` 用一个无标题编辑器完成写作、保存草稿、发布、修改和撤下；每条最多
  5,000 个 Unicode 码点，允许换行和显式 HTTP(S) 链接。错误不会清空编辑器，重复提交受控。
  停笔 1.2 秒后自动保存私有草稿，保留主动保存；首次保存生成可恢复的编辑链接。
  中文输入法组词期间不触发自动保存，保存失败保留文字并提示，发布始终需要主动操作。
  本轮不增加图片附件、转发、关注、私信或连续发帖机制。
- 新随记默认关闭留言，可按条开启现有受审核讨论。已有访客不能获得发布权。
- 首页独立露出最近一条随记，文章/影像/项目的精选区域保留；内容索引可检索所有类型。
- 日期统一按 Asia/Shanghai 显示，避免服务端与读者时区造成月份跳动。实际时间保留 ISO UTC。
- 增量迁移 `202609210002_notes.sql` 仅替换现有 `save_entry` 的内容类型和校验，保留原函数的
  权限与安全边界，不改写旧记录。旧备份仍须使用与其迁移清单一致的提交进行恢复。

## 设计依据

实际打开 [Memos 的文档](https://usememos.com/docs/usage) 研究低门槛记录与整理；在浏览器查看
[Simon Willison Notes](https://simonwillison.net/notes/) 的正文直接展开、日期与独立链接。
它们提供交互参考，未复制代码、品牌、文案或素材。

沿用 Myshkin 451 的浅色底、衬线文字标识、蓝色细节和留白。随记以日期和正文组成版面，
月份留在侧边，手机压缩为横向月份导航；不堆叠头像、社交计数和重复大标题。
使用简短功能文案，不为站主编造身份或作品。四条排版样例仅在手动开启的本机预览出现。
此版是可操作的设计提案，不代表站主已接受最终视觉。

## 发布边界

用户随后决定暂不购买域名。域名、Resend 发件域名验证及真实邮箱/首位站主验收继续待办。
这不阻止在既有 Vercel 地址发布随记功能；不能将本机测试账号当作真实站主，或将云端空状态
验收称为本人已经能够日常发布。
