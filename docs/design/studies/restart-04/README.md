## 设计判断

本轮研究阶段实际查看了 [Apple 首页](https://www.apple.com/)、
[Apple 产品详情](https://www.apple.com/iphone-18-pro/) 与
[Google DeepMind 首页](https://deepmind.google/)。以下为从页面观察转化的本站设计判断，
不代表这些品牌的设计规范，也不是对其全部体验的审计。

- **先决定看什么，再决定外框。** 减少网站自我介绍，让实际内容成为主要对象。
- **让内容有不同的密度。** 主要作品、文章与影像、紧凑随记采用不同尺度，避免全部内容变成
  同尺寸卡片或单一日期流水账。首页随真实内容变化，不永久以工具领头。
- **用操作建立连续性。** 打磨筛选、阅读、图片展开与关闭、取景和返回，而非持续动画或发光装饰。
- **标题说明对象，控件说明动作。** 中文无衬线建立基础层级，中性界面为内容让位，减少口号、
  装饰英文和替作者编造的宣言。无需为显得独特增加个人签名元素。

独立样稿验证了这一方向，完整应用随后完成整合与打磨，站主现已接受当前视觉版本。
这一接受不等于已经确定创作者身份或最终名称，也不替代真实账号与线上使用验收。

## 已整合到完整应用

| 部分 | 实现与保留的能力 |
| --- | --- |
| 首页 | 由公开条目与网站设置驱动；按真实内容、精选和日期组织；支持空站、单件作品、只有随记与混合内容 |
| 公共导航与搜索 | 作品／随记／关于、账号、手机菜单；关键词与类型搜索、Cmd/Ctrl + K、方向键、Enter 和 Escape |
| 内容目录 | 类型／话题／搜索、图文／目录视图；切换类型保留搜索与视图，详情返回保留列表状态 |
| 阅读 | 原有标题、引用、列表、代码、正文与附图；章节位置、阅读进度、字号和复制链接 |
| 影像 | 组图和附图、大图对话框、前后切换、键盘与 Escape、关闭后焦点恢复、真实图注和来源 |
| 本机取景样例 | 比例、拖动、方向键、位置／放大、参考线、原图对照、复位；本机选图和 PNG 导出 |
| 随记 | 月份／话题／搜索、长文展开、稳定链接、站主编辑、自动私有草稿、发布与撤下 |
| 账号与工作台 | 沿用既有登录／恢复边界、草稿预览、发布、媒体、讨论和审核行为，统一现代视觉基础 |

本机取景工具接受 JPG、PNG、WebP，单文件最大 20 MB；导出最长边 4096 px 的 PNG。
图片只在当前页面处理，不上传、不修改原图、不自动发布。它是明确标记的本机样例，
不是生产数据库中自动创建的项目，也不要求真实首页必须有一件工具作品。
