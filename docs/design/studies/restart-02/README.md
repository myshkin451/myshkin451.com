## 这一轮改了什么

用户认为上一轮 B 的视觉效果相对较好，但明确不满意整体设计。反复出现的口号、创作者身份
描述、拟人化提示和装饰性英文，让页面显得刻意。B 不应被记为已接受的设计方向。

这次保留深色背景与视觉作品，删除这些表达。首页只留下项目名称、类型、年份和文章入口，
图形参数移到作品详情中。新增独立的文章和关于页面，检查视觉语言能否支持阅读。

先通过内置生图工具生成 [完整效果图](concept.png)，再从效果图生成独立的
[作品图像](assets/dispersion.png)，随后用 HTML/CSS/SVG/JavaScript 实现。效果图和原始资产均已
保留在本目录。网页中的文字是真实 HTML，环面是可操作的 SVG，不是整页截图。

## 本机体验

在仓库根目录执行：

```bash
python3 -m http.server 4320 --bind 127.0.0.1 --directory docs/design/studies/restart-02
```

打开 `http://127.0.0.1:4320/index.html`。服务只暴露本目录；按 `Ctrl+C` 停止。
也可以直接打开 `index.html`，同目录文件需一起保留。

- 点击“色散”或图像，打开大图；详情标明为 AI 生成样例，可以下载。
- 打开“环面”，拖动或使用方向键旋转，调整粗细、颜色，主动开启旋转或重置。
- 点击“网站重做记录”进入文章页；“关于”进入简短介绍。
- 对话框支持 Escape 关闭、焦点返回；自动旋转默认关闭，遵循减少动态效果设置，并在关闭或隐藏页面时停止。

当前内容用于验证设计。“网站重做记录”按本轮实际改动编写并标记为样稿；没有虚构个人经历。
“色散”是生成图像，“环面”是代码实验。它们没有被写入生产 CMS。
