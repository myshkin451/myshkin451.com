## 本机体验

持续改设计时推荐本机预览，修改源文件后刷新即可。在仓库根目录执行：

```bash
python3 -m http.server 4321 --bind 127.0.0.1 --directory docs/design/studies/restart-03
```

打开 `http://127.0.0.1:4321/index.html` 或 `http://127.0.0.1:4321/catalog.html`。
服务只暴露此样稿目录，按 `Ctrl+C` 停止。文件应保持同一目录结构。
原始多文件页面直接打开时，浏览器可能限制相邻图片的 Canvas 取色；推荐使用以上本机地址。

需要留存或不启动服务时，用浏览器打开 [offline.html](offline.html)。它约 11 MiB，包含两种首页、
所有详情页、两张图片与两张效果图，不需要相邻文件或联网加载资源。GitHub 等外部链接仍需联网。
复制色值优先使用浏览器剪贴板接口，受限时尝试兼容方式；仍不可用时显示可手动复制的 HEX 值。

离线版由以下命令生成，不应直接编辑。修改 HTML、CSS、内容或脚本后重新打包：

```bash
python3 docs/design/studies/restart-03/build_offline.py
```

打包只使用 Python 标准库，保留原图字节；站内导航改为同一文件中的片段路由。

- 并排版：分类与详情入口。
- 目录版：分类、标题搜索、无结果恢复、条目选择、前后预览；返回目录保留分类、查询与选中项。
- 文章：目录跳转、标准/大字切换、关联内容。
- 图像：原图展示、双图查看器、键盘左右切换、下载、Escape 关闭与焦点返回。
- 工具：点击图片取色、方向键移动取色点、切换图像、复制 HEX 色值；没有上传或外部请求。
