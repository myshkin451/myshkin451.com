```bash
python3 -m http.server 4319 --bind 127.0.0.1 --directory docs/design/studies/restart-01
```

然后打开 `http://127.0.0.1:4319/index.html`。停止预览时按 `Ctrl+C`。

## 先体验什么

- **A / 页间**：编辑式排版。翻看印刷习作背面，打开文章试读。
- **B / 游乐室**：作品先行。调整线条雕塑的形状、颜色与旋转状态。
- **C / 线索**：内容关联。选择文字、作品或片段，查看它与主题的联系并打开内容。
- 顶部切换手机预览；“下一步”展示从样稿到可用网站、再到上线的顺序。
- 可以记下多个喜欢的方向和感受。反馈只保存在当前浏览器，点击复制后手动发回对话；没有联网提交。

## 同一组内容

三版均使用为本次研究写作的虚构示例：

1. 随笔《重新拥有一小块互联网》。
2. 交互习作《光的练习》。
3. 片段《给无用之物留个位置》。
4. 简短的关于说明。

这些文字不是已发表文章，也不是已经接受的个人声明。插图与 SVG 线条雕塑均为本次编写的
可编辑图形，没有外部图片、字体请求、分析脚本或真实 CMS 数据。

## 反馈之后

先归纳喜欢的构图、字体、内容组织与交互，再选一个主要方向补齐文章和项目详情。
不直接把三套风格拼在一起。具体视觉方向仍是 `progress.md` 中的开放决策。
