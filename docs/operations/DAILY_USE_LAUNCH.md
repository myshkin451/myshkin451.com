整体视觉的主要问题是操作优先级与实际内容缺席，不是需要再换一套颜色和字体。
沿用既有冷中性、无衬线设计；不编造个人简介、文章或学习成果填充首页。

参考的是具体行为，而非复制网站皮肤：

- [Micro.blog 的无标题短文](https://help.micro.blog/t/writing-longer-posts/27)：简短表达直接进时间线。
- [Memos 的编辑与可见范围](https://usememos.com/docs/usage/memos)：草稿保存与公开状态清楚。
- [Ghost 的发布流程](https://ghost.org/help/publishing-content/)：预览、发布、继续编辑的路径明确。

后续有价值但本次未实施：

1. **列表分页与按篇加载正文**：服务端每页和客户端初始/聚焦仍读取全部公开内容；真实条目
   积累后应测量首屏与查询大小，再分离摘要、正文和留言，保持现有搜索/月份过滤语义。
2. **图片处理**：目前保留原图字节，没有自动缩图或清理 EXIF。手机照片的体积与位置元信息
   应通过明确的媒体处理策略解决；本次没有悄悄重编码或删除原图信息。
3. **随记图片**：当前随记只支持文字与链接。若日常使用需要图文短帖，复用现有媒体与发布
   边界扩展，而非引入第二套社交服务；本次未改数据模型。
4. **公共代码包大小**：公共页面仍包含工作台相关代码。后续可按页面拆包，但需要连同 SSR、
   草稿恢复和搜索行为一起验证；不把未经测量的拆分当作今天上线的必要条件。

用户在另一任务新增“每天与本机 Codex 学习后更新路线、章节、练习、术语和知识谱系”的要求，
由学习项目负责。主站此刻不读取其私有 Git 仓库、不复制学习记录、不建立第二套进度。
可先手动选一段学习心得发为随记；真正的公开分享功能应有预览、明确范围和主动发布。

新域名上线时，哲学服务的 `frame-ancestors` 要精确允许 `https://myshkin451.com`，迁移期保留
旧来源。仅更换主站域名不需要放宽 API CORS，也不需要改变主站现有哲学 `frame-src`。
未来雅思录音优先独立全屏打开；当前主站禁止麦克风，不能直接照搬 iframe 后承诺录音可用。

## 上线顺序与剩余验收

域名、DNS、SMTP、生产部署、首次站主授权及学习嵌入已完成；以下保留流程依据，未完成项
以本文开头和云端验收记录为准，不重复购买、建号或授权。

1. **购买域名**：在 [Vercel 实时查询页](https://vercel.com/domains/search?q=myshkin451.com)
   核对 `myshkin451.com`、续费和结算总额，由本人完成付款、账号验证及注册人信息。
   本站已在 Vercel，放同一账号下可减少管理入口；不是必须迁移托管的理由。
2. **连接原项目**：给现有 Vercel 项目添加根域与 `www`，推荐 `www` 跳转根域。使用控制台
   当场给出的 DNS 记录，验证归属并等 HTTPS 可用；不照抄网上的固定 A/CNAME。
3. **认证发件服务**：候选为 Resend Free，使用独立发件子域，例如 `auth.myshkin451.com`。
   验证 DKIM/SPF，设置 SMTP 与中文确认/恢复模板；认证邮件关闭链接跟踪。
   所有密钥仅填入受保护的配置，不进入源码或对话。[详细步骤](EMAIL_SETUP.md)
4. **地址与新代码一起切换**：设置应用 `SITE_URL=https://myshkin451.com`、Supabase Auth
   Site URL、精确的 `https://myshkin451.com/auth/callback` 与 `/recover` 回跳。
   暂时保留仍在使用的旧地址。将本次验证后的代码发布到原项目，不新建数据库或导入测试数据。
5. **实际收信与站主授权**：本人在安全页面注册/收确认信/设置密码，核验邮箱后明确授予该 UUID
   站主身份；测试恢复信、新密码登录。只在真实邮件验收通过后启用正式邮箱入口。
   若需在启用前测试，可用受控部署验证；不要将“发件域验证成功”等同于收信成功。
6. **协同学习服务**：待学习任务准备好新来源后部署并验证新域 `/study`。未完成时使用独立打开，
   不为解决内嵌而允许任意网站来源；当前两套账号仍独立。
7. **本人第一次使用验收**：从手机写一条真实随记，刷新读取；写带图文章，修改草稿后确认公开
   版本不变，再发布修改；撤下能恢复草稿。再验普通访客不能访问私有内容。
8. **真实网络和回退**：常用 Wi-Fi、无代理手机流量分别检查首页、收信、图片、发布和学习。
   保留旧 Vercel 地址和已有部署回退点；沿用现有备份机制，不擅自新增备份服务。

域名/付款是本人步骤；DNS、SMTP、生产配置及部署在具体方案获准后执行。不能把本地代码
通过检查当成已经上线，也不能承诺 DNS、证书和外部邮件必定在某个时间内完成。
