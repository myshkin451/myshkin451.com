# 新一轮前端

这是可以完整浏览、编辑和发布本机内容的前端版本。它独立于根目录的旧 Next/Payload 应用，
不需要数据库、环境密钥或外部服务。旧样稿保留在 `docs/design/studies/`。

## 启动

在仓库根目录运行：

```bash
pnpm install --frozen-lockfile
pnpm frontend:dev
```

打开 `http://127.0.0.1:4323/`。固定使用同一个地址；`localhost`、`127.0.0.1` 和不同端口
有各自的浏览器存储，内容不会互通。需要关闭时，在启动终端按 Ctrl+C。

```bash
pnpm frontend:test
pnpm frontend:build
pnpm frontend:preview
```

构建产物在 `frontend/dist/`，需要通过静态 HTTP 服务打开，不是单文件离线 HTML。

## 现在可以做什么

- 首页提供文章、影像和项目入口；没有内容时仍是完整入口页，有内容后最多展示三项精选（未设置精选时展示最近发布）。
- 内容页提供图文/目录切换、搜索、形式与主题筛选；返回时保留筛选与选中项，兼容旧首页筛选链接。
- 阅读文章、使用目录、调整字号；浏览组图、总览、大图与键盘切换。
- 直接打开内部交互或站外项目，也可查看项目说明。色彩练习可调整配色、方向和复制 CSS，提供 SVG 导出。
- 从工作台写文章、上传照片、添加项目；保存不完整草稿、预览、发布、再修改、撤下。
- 图片支持 PNG/JPG/WebP/AVIF，单张不超过 10 MiB，每篇最多 20 张；支持排序、说明和替代文字。
- 修改站名、首页简介、关于页、内容页默认视图，设置精选与是否允许留言。
- 以本机演示昵称留言、回复、修改自己的留言；工作台可隐藏或恢复留言。
- 右下角“本机预览”可展开样例开关与工作台入口；不会挡住正文。

首次打开默认不显示样例。已有浏览器的显示偏好保持不变；可在预览工具中打开六项排版样例。
两张图像沿用第三轮的 AI 生成素材并保留来源标记。没有代写真实个人经历，
没有虚构访客对话。`seed.ts` 和 `types.ts` 分别定义样例与内容协议。

## 边界

数据写入当前浏览器的 IndexedDB。清除浏览器数据会删除内容；没有备份、同步或网络发布。
这个版本可以用于试用，重要原稿请另行保留。

登录、注册、找回和账号页面用于验证体验，不收集真实密码、不发送邮件。演示身份退出后再次
进入会生成新身份。工作台没有真正的权限隔离，不能把这份前端当成公开注册服务直接上线。

文章目前支持段落、`##` 标题、简单列表、引用和代码块；配图在正文后展示，第一张同时作封面。
没有富文本编辑器、自动保存、通用可视化页面搭建、专题编排或手动排序首页。新的交互作品仍
由代码实现，发布现成文章、照片和链接项目不需要改代码。

## 文件边界

- `src/App.tsx`：导航、页面装配与独立预览工具条。
- `src/pages/Home.tsx`、`home.css`：可从空内容开始的简短首页。
- `src/pages/Public.tsx`、`ColorLab.tsx`：浏览、详情、关于与交互作品。
- `src/site-shell.css`：本轮公共页的导航、字号、卡片和预览工具呈现；阅读/相册/工具的细部仍由 `public.css` 管理。
- `src/pages/Studio.tsx`：内容编辑、网站设置与留言管理。
- `src/pages/Community.tsx`：访客页面与通用讨论组件。
- `src/platform.tsx`：页面使用的数据接口；当前接本机存储。
- `src/model.ts`、`storage.ts`：内容规则与事务持久化。
- `src/Confirm.tsx`：可访问的页面内确认框。

以后接后端时保留页面与数据边界，替换本机适配器，重新验证真实账号、媒体存储、发布和权限。
最终框架与部署方案尚未确定；参见 [决策 0012](../docs/decisions/0012-independent-frontend-and-rebuild-authority.md)。

## 验证

2026-09-19：仓库格式、ESLint、类型检查和前端生产构建通过；19 项状态/持久化测试和
8 项编辑器离开保护/确认框交互测试通过。
真实浏览器已验证目录选中项与返回、搜索空状态、字号、图片查看与 Escape 焦点返回、
渐变调整与实际 CSS 剪贴板结果，以及以下 IndexedDB 流程：

- 保存文章后刷新恢复；草稿预览不出现讨论；发布后的未发布修改与公开副本隔离。
- 上传两张图片、调整顺序、发布、刷新、打开前台图集。
- 只填写链接的项目直接进入体验；隐藏样例后保留自己发布的内容。
- 登录前留言草稿保留，演示身份返回原内容，发布/回复刷新后保留，隐藏审核生效。
- 修改网站名称、简介和关于正文后，公开页面与标题更新。
- 页面内离开确认默认聚焦“继续编辑”；Escape 取消后保留文字，仍可保存。

验收写入在 `localhost:4323`，交付预览使用 `127.0.0.1:4323`，不混入验收内容。
内置浏览器未暴露 SVG 下载完成事件：已验证生成与触发入口，文件落盘尚未确认。
原生离开确认在内置浏览器工具中阻塞，因此改为页面内确认；关闭整个标签页仍依赖浏览器的
标准未保存提示。减少动态效果 CSS 已提供，未作操作系统级偏好切换测试。
320 像素下检查了首页、目录、文章、互动、留言、注册、找回、账号、设置和审核页面，
未发现横向溢出或浏览器警告/错误；桌面首页、文章、图集和工作台也已实际查看。

旧应用、数据库集成、真实身份权限、邮件与部署不在这次前端验收范围内。
